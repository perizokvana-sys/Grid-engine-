# Grid — состояние языка v0.9

Grid — компактный встроенный числовой язык движка GridEngine. Он остаётся
небольшим и предсказуемым: не GDScript, не Python и не C#. Вся «сильная» логика
пишется на C++ (нативные модули) или C# (мост поведения), Grid отвечает за
простые числовые правила на сущностях.

## Базовый синтаксис

```grid
// Комментарий до конца строки
let speed = 100;
let count = 0;
while (count < 3) {
    position_x += speed * delta;
    count += 1;
}
if (position_x > 10 && delta > 0) {
    print(position_x);
} else {
    print(0);
}
```

- `let name = expression;` объявляет числовую переменную; повторное объявление
  в той же области — ошибка.
- `name = expression;` и `name += expression;` изменяют существующую переменную.
- `print(expression);` возвращает число вызывающему коду, не пишет в консоль.
- Арифметика `+ - * /`, унарные `- !`, скобки; сравнения `< <= > >= == !=`;
  логика `&& ||`.
- `if (условие) { ... } else { ... }` и `while (условие) { ... }` используют
  ненулевые числа как истину.
- **Литеральное условие запрещено**: `if (1)` и `while (true)` — ошибка времени
  исполнения. Условие должно зависеть от переменных, иначе ветка или цикл
  статически предсказуемы и почти наверняка являются опечаткой.

## `delta` и привязка сущности

В `run_on_entity(source, scene, entity_id, delta_seconds)` переменная `delta`
содержит переданное время кадра в секундах, доступна только для чтения;
нулевое значение допустимо, отрицательное и не конечное отклоняются.
`position_x` и `position_y` доступны для чтения и изменения; изменения
применяются только после успешного выполнения всего скрипта.

```grid
position_x += 100 * delta;   // 100 единиц в секунду вправо
```

В изолированном `run(source)` переменная `delta` не задаётся: её можно
объявить через `let delta = ...;` как обычную локальную переменную.

## Скрипты на сущностях сцены

Начиная с формата `GridScene 4` у сущности есть необязательное поле `script`.
Экспортированная игра выполняет его каждый кадр через `run_on_entity`, поэтому
сцена из редактора остаётся исполняемой без перекомпиляции. Форматы 1–3
читаются как прежде (скрипт пустой), файл записывается версией 4 только если
хотя бы у одной сущности есть скрипт.

## Ограничения

У исполнения есть лимит итераций циклов (10000) и вложенности блоков (64).
Привязка к сцене ограничена трансформом одной сущности. Нет строк, функций,
пользовательских типов, компонентов и произвольных C++ вызовов: это осознанное
ограничение — для сложного поведения используйте нативные модули (C++) или
C#-мост.
