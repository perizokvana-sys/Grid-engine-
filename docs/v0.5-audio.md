# GridEngine v0.5 — Audio System (частичная реализация)

## Что включено

* `AudioSource`: относительный/абсолютный путь ресурса, Loop, громкость 0..1, Mute; строгая проверка finite/range для громкости.
* `GridAudioSource 1`: текстовая сериализация конфигурации; десериализация проверяет версию, поля, диапазон и расширение, не изменяет destination при ошибке.
* `AudioManager`: непрозрачные числовые handles, логические состояния Stopped/Playing/Paused, остановка и удаление, не хранящие ссылки на Entity.

## Важное ограничение

Это не устройство воспроизведения: библиотека декодирования/вывода звука не подключена. Manager моделирует команды и состояния, но не загружает файл с диска, не подтверждает целостность аудиоданных, не микширует звук и не создаёт звук. WAV/OGG — разрешённые по расширению ожидаемые ресурсы, а не фактически поддержанные декодеры. `create` поэтому проверяет только конфигурацию. Нельзя использовать API как подтверждение реального состояния звукового устройства.

Перед production-подключением выбрать и зафиксировать точную версию и лицензию backend (кандидат для дальнейшей оценки — miniaudio, MIT/Unlicense, single-header; файл в проект не добавлен), реализовать RAII устройства/декодеров и проверить целевые платформы. В текущем проекте отсутствуют Inspector, Asset Browser, Scene component registry и Play Mode; интеграция сцены/редактора, sandbox-демо и реальное воспроизведение не входят в этот срез. Удаление/остановка AudioManager handle безопасно, однако привязка жизненного цикла сцены пока не интегрирована.

## Проверка

`tests/audio.cpp` покрывает конфигурацию, проверку громкости, сериализацию, ошибочную версию, неподдерживаемое расширение и transitions/удаление логических handles без реального устройства. Проверки не должны трактоваться как аппаратное воспроизведение.
